### 🔒 Architectural Non-Negotiables
- **Least Privilege (PoLP):** Every role, database user, API key, and microservice has access *only* to what is required.
- **Zero-Trust Network Model:** Never trust internal traffic; mutual TLS, JWT rotation, and continuous posture evaluation.
- **Strict Input Sanitization:** Parameterized queries everywhere, contextual HTML output encoding, strict schema validation (Zod / Joi).
- **Defense in Depth:** Cloud WAF (Cloudflare / AWS WAF) ➔ Rate Limiter (Redis) ➔ Application Sanitizer ➔ DB Constraint.
- **Secret Zero Discipline:** No secrets in repos or Docker images; managed injection via HashiCorp Vault / AWS Secrets Manager / `.env` isolated.
